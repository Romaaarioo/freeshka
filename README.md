# Вилка — калькулятор вилок, фрибетов, страховок и финреза

Минималистичный веб-калькулятор для букмекерских вилок, отыгрыша фрибетов,
расчёта страховок и дневника финансовых результатов. Работает полностью
в браузере, без сервера.

**Живой демо:** https://romaaarioo.github.io/freeshka/

## Три раздела (вкладки внизу страницы)

### 1. Фришка — вилки и отыгрыш фрибета

Классический калькулятор вилок + тумблер **Фри** у каждого исхода:

- Исход 1 по умолчанию **уже фрибет** (тумблер «Фри» включён, «Фикс»
  включается и блокируется автоматически). Фрибет может быть только один;
  при переносе «Фри» на другой исход первый освобождается
- Фри-исход — это фрибет: при выигрыше букмекер начисляет только чистый
  выигрыш `W = K·C − C` (сама ставка не возвращается), а ставит его игрок
  не своими деньгами
- В режиме фрибета поле суммы у фри-исхода называется **«Номинал фрибета»**,
  а «Общая сумма» и «Мин. доходность вилки» скрываются — они не нужны:
  размеры перестраховок однозначно следуют из `W` и их коэффициентов
- Перестраховки считаются автоматически: каждая покрывает `Cⱼ = W / Kⱼ`
- Быстрые кнопки **+500 / +1000 / +5000** под таблицей задают номинал
  фрибета в один клик (в классическом режиме скрыты)
- Прибыль считается только от **реальных** ставок; в сводке видно
  «реальные ставки», номинал фрибета и **конверсию** в % от номинала
- Подсказки вместо бесполезного «мин. K ≥ 1,01» показывают экономику:
  - у фри-исхода — рекомендация **K 3–6 (оптимум 4–5)** и потолок конверсии
    `(K − 1)/K`: «хороший K · до 75 %», «низкий K», «риск лимитов»
  - у перестраховок — реальный **отыгрыш ~X %** от номинала
    `(K_f − 1)·(1 − Σ 1/Kⱼ)`, цвет зависит от выгоды
  - пока кэф перестраховки не введён — подсказки считают от честного
    противоположного кэфа `K_f/(K_f − 1)`: «противоположный ~1,33»
    и «опт. ~2 300 ₽»
- Статистика конверсии фрибетов, на которую опирается рекомендация:
  K 2.0 ≈ 50 %, 3.0 ≈ 67 %, 4.0 ≈ 75 %, 5.0 ≈ 80 %, 6.0 ≈ 83 %.
  Ниже 2.0 — теряете деньги, выше 6 — растёт дисперсия и риск лимитов

### 2. Страховка

- Исход 1 — основная ставка (фикс включён по умолчанию), все следующие
  исходы — перестраховки первого
- Сверху — **итог по каждому исходу**: «Если сыграет Исход 1: +X ₽»,
  «Если сыграет Исход 2: +Y ₽» и т.д.
- Подсказки подсказывают минимальную и оптимальную сумму страховки

### 3. Фин рез — дневник результатов

- Понимает **сегодняшнюю дату** (локальное время, не UTC) и сам обновляет
  «сегодня» после полуночи и при возврате на вкладку
- Добавление результата: **дата** (по умолчанию сегодня, будущее запрещено),
  **плюс/минус** и **сумма**; быстрые кнопки **+100 / +500 / +1000**
  подставляют сумму в один клик
- Сверху — результаты за **сегодня / 7 дней / 30 дней / всё время**
  (скользящие окна)
- **Банкролл и ROI**: укажите стартовый банк — увидите текущий банкролл
  (банк + весь результат) и **ROI** в %; хранится отдельно (`vilk-fin-bank`)
- Дополнительно: **лучший день**, **среднее за 30 дней**, число записей
- **График за 30 дней** с переключателем: «Накопительно» (кривая баланса)
  и «По дням» (столбики +/- каждого дня), зелёный/красный по знаку итога
- История сгруппирована по дням с итогом каждого дня, каждую запись можно
  удалить, всё — очистить одной кнопкой с подтверждением
- **Экспорт/импорт JSON**: файл `finrez-<дата>.json`; импорт объединяет
  записи (дубликаты по id не создаются)
- Данные хранятся в `localStorage` (`vilk-fin`) и синхронизируются между
  вкладками браузера

## Возможности

- Столбцы: **Коэф-т · Сумма · Прибыль этого исхода**
- Сверху — **Прибыль в ₽ и %** + индикатор состояния
- Распределение **общей суммы** по исходам автоматически (пропорционально 1/K)
- Общая сумма `0` или пустая → суммы вводятся вручную
- Тумблер **Фикс** — зафиксировать сумму на конкретном исходе
- **Кратность суммы**: округление ставок до 100 / 500 / 1000 ₽
- **Мин. доходность вилки** (порог 0…3 %): слабые вилки помечаются жёлтым
- Подсказки под каждым исходом: мин. K, мин. и опт. сумма (в кратности)
- Три оформления: тёмная, светлая и **стиль GTA VI** (кнопки 🌴 и 🌙 в шапке)
- Кнопка **«+ Добавить исход»** (по умолчанию 2, до 12)
- Выбранная вкладка и тема запоминаются в `localStorage`

## Мобильная версия

- Поля и кнопки не мельче 48 px, шрифт полей 16 px — iOS Safari не
  приближает страницу при фокусе (из-за этого «камера» больше не уезжает)
- Учтены безопасные отступы iPhone (вырез, боковые края, домашний индикатор),
  нижнее меню закреплено над ними и не перекрывает последний блок
- Когда открывается клавиатура, активное поле автоматически поднимается
  над нижним меню
- Карточки, строки исходов и форма «Фин рез» перестраиваются под ширину
  320–430 px без горизонтальной прокрутки и наложений

## Формулы

Обозначения: `Kᵢ` — коэффициент исхода, `T` — общая сумма, `Cᵢ` — ставка на исход.

1. Сумма обратных коэффициентов (вероятности исходов):

   ```
   S = 1/K₁ + 1/K₂ + … + 1/Kₙ
   ```

2. Вилка существует, если `S < 1`. Доходность:

   ```
   Прибыль % = (1/S − 1) · 100
   ```

3. Распределение общей суммы (выплата по каждому исходу одинакова):

   ```
   Cᵢ = T · (1/Kᵢ) / S        выплата = Kᵢ·Cᵢ = T/S
   ```

4. Фиксированный исход j (тумблер «Фикс»):

   ```
   P = Kⱼ · Cⱼ  (выплата якоря)
   Cᵢ = P / Kᵢ                 остальные исходы
   оборот = P · S,  прибыль = P · (1 − S)
   ```

5. Прибыль конкретного исхода:

   ```
   Прибыльᵢ = Kᵢ · Cᵢ − Σ C
   ```

6. Минимальный коэффициент исхода i, при котором доходность ещё ≥ t
   (подсказка под полем):

   ```
   Kᵢ_min = 1 / (1/(1+t) − Σ_{j≠i} 1/Kⱼ)
   ```

7. Фрибет (раздел «Фришка»): чистый выигрыш и перестраховки:

   ```
   W = K_f·C_f − C_f        (ставка фрибета не возвращается)
   Cⱼ = W / Kⱼ              (каждая перестраховка покрывает W)
   Прибыль = W·(1 − Σ 1/Kⱼ)
   Конверсия = Прибыль / C_f = (K_f − 1)·(1 − Σ 1/Kⱼ) · 100 %
   Потолок конверсии при честном кэфе = (K_f − 1) / K_f
   ```

   Рекомендация: `K_f` в диапазоне **3–6** (оптимум 4–5). При K 3/4/5/6
   потолок конверсии ≈ 67/75/80/83 %. При K < 2 конверсия падает ниже 50 %,
   при K > 6 растёт дисперсия и риск лимитов.

8. Страховка (раздел «Страховка»): исход 1 — фикс, остальные его
   перестраховывают; прибыль каждого исхода — формула (5), итог по каждому
   исходу выведен сверху.

9. Фин рез (раздел «Фин рез»): результат за окно — сумма записей с датой
   в этом окне (локальные даты, включая сегодня):

   ```
   Сегодня = Σ записей с датой = сегодня
   7 дней  = Σ записей с датой ∈ [сегодня − 6, сегодня]
   30 дней = Σ записей с датой ∈ [сегодня − 29, сегодня]
   Всего   = Σ всех записей
   Среднее за 30 дней = (30 дней) / 30
   ```

   График — накопительная сумма по дням за 30 дней (с учётом остатка
   записей до начала окна) либо столбики дневных результатов (режим «По дням»).

10. Банкролл и ROI (при указанном стартовом банке `B₀ > 0`):

    ```
    Банкролл = B₀ + Всего
    ROI = Всего / B₀ · 100 %
    ```

При включённой кратности ставки округляются до ближайших кратных, поэтому
прибыли по исходам могут немного отличаться — колонка «Прибыль этого исхода»
показывает это честно.

## Запуск локально

Просто откройте `index.html` в браузере. Сборка не нужна.

## Структура

```
freeshka/
├── index.html   — разметка
├── style.css    — стили (тёмная/светлая тема через CSS-переменные)
└── app.js       — вся логика расчёта
```

## Публикация (GitHub Pages)

1. Создайте репозиторий `freeshka` на GitHub (без README).
2. Запушьте код:

   ```bash
   git init -b main
   git add .
   git commit -m "feat: arbitrage calculator"
   git remote add origin https://github.com/Romaaarioo/freeshka.git
   git push -u origin main
   ```

3. Включите Pages: **Settings → Pages → Source: Deploy from a branch →
   Branch: main / (root) → Save**.
4. Сайт появится по адресу `https://<username>.github.io/freeshka/`
   (может занять пару минут).
